БАЛАНС ВЗАИМОРАСЧЁТОВ · версия 1.8.6

ОБНОВЛЕНИЕ НА SHAREPOINT
1. Замените index.html файлом из архива.
2. Сохраните ваши действующие ссылки на Excel, конфиг и рабочую папку.
3. Добавьте в действующий balance-config.json блок aiSearch из нового конфига. В публичной версии адрес API, модель и ключ пустые; заполните эти поля в своём конфиге на SharePoint.
   Альтернатива: введите эти параметры в «Администрирование → ИИ-поиск GLM», нажмите «Применить и скачать настройки» и замените конфиг скачанным файлом.
4. Файл balance-config.json должен лежать рядом с HTML; поддерживается прежняя папка config/. Если он расположен отдельно, укажите configUrl в HTML или параметр ?config=...
5. Откройте приложение заново. Значок ИИ возле каждого поиска переключает режим; Enter или ↵ выполняет запрос. Для корпоративного API нужен доступ из корпоративной сети.

В новом начальном конфиге contractors: null — список берётся из Excel. Никаких тестовых подрядчиков в нём нет. Если используете полный новый конфиг, перенесите в него ваши sourceUrl, configUrl и workspaceUrl.

Подсветка: положительные БГ, ГУ, КЗ и НЗП × 0,8 — красные ячейки; обычный НЗП не подсвечивается; отрицательный остаток в мосте — красный столбик. В общем балансе KPI скрыты. Excel и печать находятся на одной линии с поисками и имеют одинаковую с ними высоту, CSV удалён. При поиске показателя таблица располагается сверху и сохраняет обычную высоту строк.

Приложение не записывает файлы на SharePoint самостоятельно и не использует постоянное хранилище браузера. Скачанные HTML и JSON размещает пользователь. Подробности и проверки — в README.md.

В хедере — логотип СИБУР из «Справочника». Справа от заголовка баланса — дата последнего обновления исходного Excel на SharePoint, по московскому времени. Если дата не получена, показано «Дата обновления недоступна». Настроенный конфиг предыдущей версии совместим с этим обновлением.

Версия 1.8.6: текст и значения KPI тёмно-серые, цветные подложки убраны. Поля поиска расширены. Оба поиска по умолчанию работают через ИИ; ошибки сумм меньше 1 в выбранных единицах не подсвечиваются.

Excel-выгрузка по выбранному подрядчику содержит только активный лист баланса и выбранные договоры, с оформлением исходного шаблона. На дополнительном листе «Мост и авансы» — мост и таблица процентов и сумм зачёта авансов. В режиме «Все подрядчики» сохраняются все четыре исходных листа. Мост — видимые редактируемые объекты Excel, фиксирующие вид на момент выгрузки; под ним — числовая таблица шагов. Ссылки формул на удалённые листы заменяются исходными рассчитанными значениями. При ширине окна до 1800 px ключевые показатели скрываются автоматически.

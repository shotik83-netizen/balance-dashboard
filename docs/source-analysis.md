В объединённом меню — 25 подрядчиков. Наборы договоров исходных листов не совпадают. В последнем листе есть Подрядчик 25, которого нет в рублёвом балансе с НДС; валютные листы охватывают Подрядчиков 1, 2, 3 и 17.

## Существенные особенности

- Повторяющиеся названия подрядчиков без номера договора — промежуточные итоги. Их нельзя складывать с колонками договоров.
- Некоторые самостоятельные колонки не содержат номера договора. Они сохраняются в приложении как «Без номера · буква».
- Названия строк и номера строк различаются между листами. Они читаются отдельно, без универсального пересчёта НДС.
- В валютном отчёте с НДС строка 5 содержит рублёвую оценку принятия и не имеет названия в колонке B. Денежный отчёт в валюте начинается с подписанной стоимости в строке 6. Строка 5 не включена как безымянный валютный показатель.
- Общий заголовок валютного листа без НДС ошибочно содержит «с НДС». Режим определяется именем листа и его фактической структурой.
- В разных формулах встречаются собственные правила расчёта, включая деление НЗП на 1,22. Приложение сохраняет результат исходника вместо распространения этого коэффициента на все статьи.
- В отчёте НЗП отдельные строки выполнения заданы вручную и могут расходиться с суммой КС-2 и НЗП. Они показаны как в Excel.
- Пустая ячейка не считается подтверждённым нулём. При неполных исходных данных итог помечается звёздочкой.
- Дата актуальности извлекается из соответствующей ячейки листа; время загрузки показано отдельно.

## Проверено автоматически

- Чтение исходного XLSX средствами того же ZIP/XML-парсера, который включён в приложение.
- Сверка **2 898 числовых ячеек** со значениями независимого чтения книги.
- Правильное количество колонок договоров и исключение промежуточных итогов.
- Выбор одного подрядчика и одного договора; второй договор отсутствует в выгрузке.
- Переключение валютного отчёта с НДС на исходный лист без НДС.
- Раздельные итоги USD и EUR после настройки индивидуальной валюты.
- Пересчёт валютного значения в RUB с курсом 89,79 на уровне функции преобразования. В интерфейсе режим RUB по умолчанию читает самостоятельный рублёвый лист.
- Масштаб, округление, отрицательные значения, проценты и пустые ячейки.
- Создание XLSX и его повторное чтение; сохранение числовых значений и одного договора.
- Применение настроек и автоматическое скачивание JSON.
- Отклонение неверной конфигурации и недопустимого URL.
- Отсутствие кода хранения данных в браузере.

Результат автоматических проверок: **PASS**.

Полная визуальная проверка в браузере и чтение непосредственно с корпоративного SharePoint в этой среде не выполнены. Для SharePoint требуется прямая ссылка пользователя и разрешение портала на исполнение HTML и чтение файла. Разработка не изменяла действующий проект «Финансовая модель».
